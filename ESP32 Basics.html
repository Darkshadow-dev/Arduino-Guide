01 • INTRODUCTION

What is an ESP32?

The ESP32 is a microcontroller family commonly used in electronics, robotics and Internet of Things projects. Many ESP32 boards include Wi-Fi and Bluetooth, alongside GPIO pins for connecting components.

This guide is written for a classic ESP32 development board such as the ESP32-WROOM-32S, including common 30-pin boards. Other ESP32 models can have different pins and features.

02 • PREPARATION

What you need

  • An ESP32 development board and its USB cable.
  • A computer with Arduino CLI installed.
  • A USB data cable (some cables provide power only).
  • Optional: a breadboard, LED and suitable resistor.

Your board may use a USB-to-serial chip such as CP210x or CH340. If Windows does not show a new COM port when you connect the board, you may need the correct USB-to-serial driver for your board.

03 • INSTALLATION

Install ESP32 support in Arduino CLI

Arduino CLI can compile and upload ESP32 sketches. You do not need to use the Arduino IDE if you prefer working from Command Prompt, scripts or another editor.

Step 1 — Add the Espressif board package URL

arduino-cli config add board_manager.additional_urls https://espressif.github.io/arduino-esp32/package_esp32_index.json

Step 2 — Update the board index

arduino-cli core update-index

Step 3 — Install the ESP32 platform

arduino-cli core install esp32:esp32

Step 4 — Check that it is installed

arduino-cli core list

The platform should appear in the list as esp32:esp32. The first installation can take a while because CLI downloads the compiler, tools and board definitions.

04 • FIRST SKETCH

Create your first .ino project

Arduino sketches use the .ino extension. The sketch file should be inside a folder with the same name. 

ESP32_Test/
└── ESP32_Test.ino

ESP32_Test.ino

#define LED_PIN 2

void setup() {
    Serial.begin(115200);

    pinMode(LED_PIN, OUTPUT);

    Serial.println("ESP32 started!");
}

void loop() {
    digitalWrite(LED_PIN, HIGH);
    Serial.println("LED ON");
    delay(1000);

    digitalWrite(LED_PIN, LOW);
    Serial.println("LED OFF");
    delay(1000);
}

This sketch starts serial communication, configures GPIO 2 as an output, and switches it on and off every second. GPIO 2 is used as an onboard LED pin on some boards, but not all. If your board has no LED connected to GPIO 2, use an external LED with a resistor and the correct wiring for your board.

What the functions do

Code basics
  • setup() runs once after startup or reset.
  • loop() repeats while the board is running.
  • pinMode() configures a GPIO pin.
  • digitalWrite() sets a digital output HIGH or LOW.
  • delay(1000) waits approximately one second.
  • Serial.println() sends text to the serial monitor.
05 • BUILD & UPLOAD

Find, compile and upload your board

Step 1 — Connect the ESP32

Connect the board with USB, then list detected ports:

arduino-cli board list

Step 2 — Select a board configuration

For a classic ESP32-WROOM-32S development board, the generic ESP32 Dev Module configuration is a useful starting point. Its FQBN is: 

esp32:esp32:esp32

To see other available ESP32 board definitions:

arduino-cli board listall esp32

Step 3 — Compile the sketch

arduino-cli compile --fqbn esp32:esp32:esp32 ESP32_Test

Step 4 — Upload it

Replace COM5 with the port shown on your computer:

arduino-cli upload -p COM5 --fqbn esp32:esp32:esp32 ESP32_Test

Step 5 — Open the serial monitor

arduino-cli monitor -p COM5 -c baudrate=115200

You should see ESP32 started!, followed by LED ON and LED OFF messages. Close the serial monitor before uploading again if the port is busy.

If upload does not start

Troubleshooting
  • Check that you selected the correct COM port.
  • Try another USB cable; it must support data.
  • Close other programs using the serial port.
  • On some boards, hold the BOOT button while the uploader connects, then release it when writing begins.
  • Check the board's USB-to-serial driver if no port appears.

07 • HARDWARE BASICS

GPIO pins and safety

A classic ESP32 uses 3.3V logic. Its GPIO pins are not 5V tolerant: never connect a 5V signal directly to an ESP32 GPIO.

  • GPIO 6–11: normally used by the module's flash memory; avoid using them as ordinary GPIO.
  • GPIO 34–39: input-only on the classic ESP32.
  • GPIO 0, 2, 5, 12 and 15: strapping pins; their levels during startup can affect booting.
  • GPIO 1 and 3: commonly used for UART serial communication and programming.

Pin availability varies by board. Check the pinout for your exact ESP32 module before wiring components. Use a suitable driver for motors, relays and other loads; do not power them directly from GPIO.
