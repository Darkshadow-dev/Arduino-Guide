🖥 Serial Monitor

The Serial Monitor allows Arduino to send data directly to your computer.

Difficulty: Beginner
Main Topic: Communication
Functions: Serial.begin(), Serial.println() 
void setup(){

  Serial.begin(9600);

}

void loop(){

  Serial.println("Hello Arduino");

  delay(1000);

}

📘 Code Breakdown

v1 Beginner
  • setup() runs once when Arduino powers on.
  • Serial.begin(9600) starts communication.
  • loop() repeats forever.
  • Serial.println() prints text to the monitor.
  • delay(1000) pauses for 1 second.

🐞 Common Problems

Fixes
  • Wrong COM port selected
  • Wrong board selected
  • Missing semicolon ;
  • Serial Monitor baud mismatch

💡 LED Blink

Control outputs using digitalWrite(). 

void setup(){

  pinMode(13, OUTPUT);

}

void loop(){

  digitalWrite(13, HIGH);

  delay(500);

  digitalWrite(13, LOW);

  delay(500);

}

⚡ Important Concepts

  • HIGH turns the LED ON
  • LOW turns the LED OFF
  • pinMode() sets pin behavior
  • Digital pins only have ON/OFF states

🔘 Button Input

Read physical buttons and trigger actions. 

int button = 2;

void setup(){

  pinMode(button, INPUT_PULLUP);

  Serial.begin(9600);

}

void loop(){

  if(digitalRead(button) == LOW){

    Serial.println("Pressed");

  }

}

📘 Input Pullup Explained

INPUT_PULLUP enables the internal resistor inside the Arduino board. No external resistor is needed.

🎛 Sensor Tutorials

🌡 Analog Sensor Reading

int sensor = A0;

void setup(){

  Serial.begin(9600);

}

void loop(){

  int value = analogRead(sensor);

  Serial.println(value);

  delay(500);

}

📘 Analog Reading

  • analogRead() returns 0-1023
  • A0 is an analog input
  • Higher voltage = larger value
  • Useful for sensors and potentiometers

📏 Ultrasonic Distance Sensor

long duration;
int distance;

void setup(){

  pinMode(9, OUTPUT);
  pinMode(10, INPUT);

  Serial.begin(9600);

}

void loop(){

  digitalWrite(9, LOW);
  delayMicroseconds(2);

  digitalWrite(9, HIGH);
  delayMicroseconds(10);

  digitalWrite(9, LOW);

  duration = pulseIn(10, HIGH);

  distance = duration * 0.034 / 2;

  Serial.println(distance);

}

🧠 Advanced Tutorials

⏱ millis() Instead of delay()

Professional Arduino programs avoid delay(). millis() allows multitasking. 

unsigned long t = 0;

void setup(){

  pinMode(LED_BUILTIN, OUTPUT);

}

void loop(){

  if(millis() - t > 1000){

    t = millis();

    digitalWrite(
      LED_BUILTIN,
      !digitalRead(LED_BUILTIN)
    );

  }

}

📘 Why millis() Matters

  • No program freezing
  • Run multiple systems together
  • Essential for robotics
  • Professional coding method

Why won't my Arduino upload?

Ensure baud rate matches Serial.begin().
