    IDE / CLI Setup

    Arduino IDE Setup
  • 🧰 Open Arduino IDE after installation
  • Go to File → Preferences
  • Paste board manager URL if needed (ESP32 / ESP8266 etc.)
  • Go to Tools → Board and select your board
  • Go to Tools → Port and select USB port

    • Now your IDE is ready to upload code.

    Arduino CLI Setup
  • ⌨️ Open terminal / CMD
  • Run: arduino-cli version
  • Install core: arduino-cli core update-index
  • Install board: arduino-cli core install arduino:avr
  • Check device: arduino-cli board list

    • Now CLI is ready for compiling and uploading.

    Setup Summary

    • IDE = visual setup (click-based)
    • CLI = terminal-based control
    • Both need board + port configured

    First Arduino Project

    Before You Start

    • Make sure Arduino IDE or CLI is installed
    • Connect your Arduino board with USB cable
    • Check that drivers are installed (if needed)
    Step 1: Prepare Board (IDE)
  • Open Arduino IDE
  • Go to Tools → Board → select your board (e.g. Arduino Uno)
  • Go to Tools → Port → select USB port

    • If port is missing, reconnect USB or install drivers.

    Step 1: Prepare Board (CLI)
  • Open CMD / Terminal
  • Run: arduino-cli board list
  • Confirm your board appears in the list
  • If not, reconnect USB cable

    • Then install board core if needed:

    arduino-cli core update-index
arduino-cli core install arduino:avr
    Step 2: Wiring (LED Setup)
  • Connect LED long leg → Pin 13
  • Connect LED short leg → 220Ω resistor
  • Resistor → GND (ground pin)

    • This prepares hardware for testing.

    Step 3: Write Code (IDE)
  • In Arduino IDE click New Sketch
  • Delete default code
  • Paste this code:
    • void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
    Step 3: Write Code (CLI)
  • Create file: blink.ino

    • Paste same code into file:

    void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}
    Step 4: Upload Code
  • IDE: Click Upload button (→ arrow icon)
  • CLI: Run commands:
    • arduino-cli compile --fqbn arduino:avr:uno blink
arduino-cli upload -p COM3 --fqbn arduino:avr:uno blink

    (Replace COM3 with your actual port)

    Step 5: Test Result
  • LED should turn ON for 1 second
  • Then OFF for 1 second
  • If nothing happens:
    • Check wiring direction of LED
    • Check board port selection
    • Try different USB cable

    What You Learned

    • How Arduino code structure works
    • How upload process actually runs
    • How to test and debug hardware

    Advanced Blink

    Custom Blink Speed

    Change delay values to control speed:

    void loop() {
  digitalWrite(13, HIGH);
  delay(200);
  digitalWrite(13, LOW);
  delay(200);
}
    Multiple LEDs Blink

    Connect LEDs to pins 8, 9, 10

    void setup() {
  pinMode(8, OUTPUT);
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
}

void loop() {
  digitalWrite(8, HIGH);
  digitalWrite(9, LOW);
  digitalWrite(10, HIGH);
  delay(500);
}

    Quick Wiring Guide

    Basic LED Wiring
  • LED long leg → Pin 13
  • LED short leg → GND
  • Add 220Ω resistor in series
    • Button Wiring
  • One side → 5V
  • Other side → Pin 2
  • Use 10kΩ pull-down resistor
    • Sensor Wiring
  • VCC → 5V
  • GND → GND
  • OUT → Analog pin (A0)

    • Important Notes

    Before You Continue

    • Always double-check wiring before powering board
    • Wrong wiring can damage components
    • Use resistors for LEDs and sensors

    Programming Tips

    • Start with simple code first
    • Test one component at a time
    • Use Serial Monitor for debugging
