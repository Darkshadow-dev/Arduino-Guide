INTERMEDIATE · PROGRAMMING

Non-Blocking Timing

Learn how to use millis() to control timing without stopping the entire Arduino program with delay().

millis() Timing Arduino Uno

Why delay() becomes a problem

delay() completely pauses the program for the specified amount of time. This is fine for simple projects, but becomes a problem when several things need to happen at once. 

digitalWrite(LED_BUILTIN, HIGH);
delay(1000);
digitalWrite(LED_BUILTIN, LOW);
delay(1000);

During those delays your program cannot normally perform other tasks in the same loop.

Using millis()

millis() returns the number of milliseconds that have passed since the Arduino started running the sketch. 

unsigned long previousMillis = 0;
const unsigned long interval = 1000;

void setup() {
    pinMode(LED_BUILTIN, OUTPUT);
}

void loop() {
    unsigned long currentMillis = millis();

    if (currentMillis - previousMillis >= interval) {
        previousMillis = currentMillis;

        digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));
    }
}
The program keeps running while it waits for the next interval. This allows other code to execute inside loop().

Multiple timers

One of the biggest advantages of millis() is that different parts of your project can have different schedules. 

unsigned long lastLED = 0;
unsigned long lastSerial = 0;

void loop() {
    unsigned long now = millis();

    if (now - lastLED >= 500) {
        lastLED = now;
        digitalWrite(LED_BUILTIN, !digitalRead(LED_BUILTIN));
    }

    if (now - lastSerial >= 1000) {
        lastSerial = now;
        Serial.println("Running...");
    }
}

Try It

Make one LED blink every 500 ms while the Serial Monitor prints a message every 2 seconds.

Sensors

Move beyond simply reading a sensor. Learn how to process sensor values and turn them into useful decisions and outputs.

Analog Digital Sensor Data Arduino Uno

Reading a sensor

Many Arduino sensors provide either an analog value or a digital state. Analog inputs on the Uno normally produce values from 0 to 1023. 

int sensorValue = analogRead(A0);

Serial.println(sensorValue);

delay(200);

Turning a reading into a decision

int sensorValue = analogRead(A0);

if (sensorValue > 600) {
    digitalWrite(LED_BUILTIN, HIGH);
} else {
    digitalWrite(LED_BUILTIN, LOW);
}

This creates a simple threshold system. The same idea can be used for light sensors, potentiometers, joysticks and many other inputs.

Mapping values

map() can convert a value from one range into another. 

int sensorValue = analogRead(A0);

int brightness = map(
    sensorValue,
    0,
    1023,
    0,
    255
);

analogWrite(9, brightness);
map() changes the numerical range. It does not automatically smooth noisy sensor readings.

Try It

Connect a potentiometer to A0 and use its position to control the brightness of an LED on a PWM pin.

OLED Interfaces

Build useful OLED interfaces that display sensor values, status information, menus and other project data.

OLED I²C Display Adafruit GFX

Basic OLED structure

A typical I²C OLED uses SDA and SCL for communication. On an Arduino Uno these are A4 and A5. 

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

Adafruit_SSD1306 display(128, 64, &Wire, -1);

void setup() {
    display.begin(
        SSD1306_SWITCHCAPVCC,
        0x3C
    );

    display.clearDisplay();
    display.setTextColor(SSD1306_WHITE);
    display.setTextSize(1);
    display.setCursor(0, 0);
    display.println("Arduino");
    display.display();
}

void loop() {
}

Displaying changing values

int value = analogRead(A0);

display.clearDisplay();

display.setCursor(0, 0);
display.println("Sensor:");

display.setCursor(0, 20);
display.println(value);

display.display();

The important pattern is to draw the new screen and then call display.display() to send the buffer to the OLED.

Building an interface

Header

Project name or current mode.

Main Value

Sensor reading or important information.

Status

Show whether something is active.

Controls

Show available buttons or joystick actions.

State Machines

Learn how to structure projects around clearly defined states instead of creating increasingly complicated conditions.

Logic Program Flow State

What is a state?

A state represents what your project is currently doing.

MENU

The user is selecting something.

GAME

The main program is running.

PAUSED

The project is temporarily stopped.

ERROR

The project detected a problem.

Simple state system

enum State {
    MENU,
    GAME,
    PAUSED
};

State currentState = MENU;

void loop() {

    switch (currentState) {

        case MENU:
            runMenu();
            break;

        case GAME:
            runGame();
            break;

        case PAUSED:
            runPaused();
            break;
    }
}

Changing state

if (buttonPressed) {
    currentState = GAME;
}

if (pausePressed) {
    currentState = PAUSED;
}

This becomes especially useful for OLED menus, games, control panels and projects with several operating modes.

Multiple Inputs

Learn how to handle several buttons, switches, joysticks and other inputs inside the same project.

Buttons Joystick Digital Input

Using several buttons

const int buttonA = 2;
const int buttonB = 3;
const int buttonC = 4;

void setup() {
    pinMode(buttonA, INPUT_PULLUP);
    pinMode(buttonB, INPUT_PULLUP);
    pinMode(buttonC, INPUT_PULLUP);
}

void loop() {

    if (digitalRead(buttonA) == LOW) {
        Serial.println("Button A");
    }

    if (digitalRead(buttonB) == LOW) {
        Serial.println("Button B");
    }

    if (digitalRead(buttonC) == LOW) {
        Serial.println("Button C");
    }
}
INPUT_PULLUP uses the Arduino's internal pull-up resistor. With this arrangement the button reads LOW when pressed.

Combining digital and analog inputs

int x = analogRead(A0);
int y = analogRead(A1);

bool button = digitalRead(2) == LOW;

if (button && x > 700) {
    Serial.println("Action!");
}

INTERMEDIATE · OUTPUT

PWM Control

Learn how PWM can be used to control LED brightness and compatible hardware such as motor drivers.

PWM analogWrite() Arduino Uno

What PWM does

On the Arduino Uno, PWM rapidly switches a digital output on and off. The duty cycle controls how much of the time the signal is HIGH.

PWM is available on pins 3, 5, 6, 9, 10 and 11 on a standard Uno.

LED brightness

const int led = 9;

void setup() {
    pinMode(led, OUTPUT);
}

void loop() {

    for (int brightness = 0;
         brightness <= 255;
         brightness++) {

        analogWrite(led, brightness);
        delay(5);
    }
}

Using a sensor

int sensor = analogRead(A0);

int brightness = map(
    sensor,
    0,
    1023,
    0,
    255
);

analogWrite(9, brightness);
analogWrite() does not produce a true variable analog voltage on a normal Uno PWM pin. It produces a PWM signal.

Use a potentiometer to smoothly control an LED's brightness.

Serial Commands

Turn the Serial Monitor into a simple command interface for controlling and testing your Arduino.

Serial Commands Debugging

Reading Serial input

void setup() {
    Serial.begin(9600);
    Serial.println("Arduino Ready");
}

void loop() {

    if (Serial.available()) {

        char command = Serial.read();

        if (command == '1') {
            digitalWrite(LED_BUILTIN, HIGH);
        }

        if (command == '0') {
            digitalWrite(LED_BUILTIN, LOW);
        }
    }
}

Building commands

if (Serial.available()) {

    String command = Serial.readStringUntil('\n');
    command.trim();

    if (command == "on") {
        digitalWrite(LED_BUILTIN, HIGH);
        Serial.println("LED ON");
    }

    else if (command == "off") {
        digitalWrite(LED_BUILTIN, LOW);
        Serial.println("LED OFF");
    }

    else {
        Serial.println("Unknown command");
    }
}

Custom Functions

Learn how to divide larger Arduino programs into reusable pieces that are easier to understand and maintain.

Functions Code Structure Reusable Code

Why use functions?

Instead of placing everything inside loop(), you can give related operations their own functions. 

void turnLEDOn() {
    digitalWrite(LED_BUILTIN, HIGH);
}

void turnLEDOff() {
    digitalWrite(LED_BUILTIN, LOW);
}

void loop() {

    turnLEDOn();
    delay(500);

    turnLEDOff();
    delay(500);
}

Functions with parameters

void setLED(int pin, int state) {
    digitalWrite(pin, state);
}

void loop() {

    setLED(8, HIGH);
    delay(500);

    setLED(8, LOW);
    delay(500);
}

Functions that return values

int readSensor() {
    return analogRead(A0);
}

void loop() {

    int value = readSensor();

    Serial.println(value);

    delay(200);
}

Create functions for reading a sensor, controlling an LED and printing the sensor value.

Using Libraries

Learn what Arduino libraries provide, how to use them and how to understand unfamiliar library functions.

Libraries Code APIs

What is a library?

A library is reusable code written to provide functionality that would otherwise need to be written manually.

Display libraries, sensor libraries and communication libraries are common examples.

Including a library

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#include tells the compiler that your sketch needs declarations provided by the library.

Learning a library

  1. Find the library documentation or examples.
  2. Look at the constructor or setup code.
  3. Find the functions you need.
  4. Start with the library's example.
  5. Change one thing at a time.
Arduino libraries often include example sketches. These are one of the fastest ways to understand how a library is intended to work.

I²C Devices

Learn how multiple devices can communicate with an Arduino through the same I²C bus.

I²C SDA SCL Addresses

The I²C bus

I²C uses two main communication lines: SDA for data and SCL for the clock.

SDA

Serial Data

SCL

Serial Clock

On a standard Arduino Uno, SDA is A4 and SCL is A5.

Device addresses

I²C devices normally have addresses. This allows a controller to communicate with a specific device on the bus.

For example, an OLED commonly uses an address such as 0x3C, although the actual address depends on the module.

Multiple devices

Several compatible I²C devices can share SDA and SCL as long as their addresses do not conflict and the electrical requirements are satisfied. 

Arduino A4 ───── SDA ───── Device A
                     └──── Device B

Arduino A5 ───── SCL ───── Device A
                     └──── Device B

Data Processing

Learn how to turn raw Arduino readings into useful information using ranges, averages, mapping and calculations.

Sensor Data Math Filtering

Raw data

int value = analogRead(A0);

Serial.println(value);

Raw sensor values are often not the final values your project needs. Processing lets you turn them into something more useful.

Average readings

long total = 0;

for (int i = 0; i < 10; i++) {
    total += analogRead(A0);
}

int average = total / 10;

Serial.println(average);

Taking several readings and averaging them can reduce the effect of small changes and electrical noise.

Convert the data

int raw = analogRead(A0);

int percent = map(
    raw,
    0,
    1023,
    0,
    100
);

Serial.print(percent);
Serial.println("%");

Use processed data

int raw = analogRead(A0);

int percent = map(
    raw,
    0,
    1023,
    0,
    100
);

if (percent < 20) {
    Serial.println("LOW");
}
else if (percent < 80) {
    Serial.println("NORMAL");
}
else {
    Serial.println("HIGH");
}

Try It

Read a sensor ten times, calculate the average, convert the result into a percentage and display LOW, NORMAL or HIGH.
